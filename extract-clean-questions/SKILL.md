# 净题提取

## 已约定的行为

- 支持所有学科及语言，保留原语言、原题意、顺序、必要材料、选项、小问、表格、公式和配图。不翻译、不解题、不主动纠正原题、不去重。语言支持是处理目标，不能在字体或 OCR 不支持时声称已正确完成。
- 保留印刷原题和手写原题；删除后加的手写答案、演算、圈画、勾叉、批改及其他作答痕迹。不要用“手写”这一特征直接删除内容。
- 提取例题、练习、课后题和试卷题；删除答案、解析、解题过程和全部解题提示，包括印刷答案和图内答案。题干提供的已知条件、作答示例和作为考查对象的公式、文字或证明不是答案，必须保留。
- 删除封面、版权页、序言、目录、广告、纯知识讲解、原页眉页脚、原页码及与答题无关的考试说明。保留章节名称及题目依赖的公共材料或必要说明。
- 按原一级章／单元拆分，保留有意义的节标题；无章节的多套试卷按套拆分，其余作为单个单元。每章题号和 PDF 页码各从 1 开始，小问保留层级。题内引用的旧题号同步改为新题号。
- 多文件分别处理，不合并、不去重；每章各交付 `.md`、`.tex`、`.pdf` 和配图资源，不生成全书合并版。
- A4 纵向、单栏、黑白友好；每道需书写过程的大题后留 4.5 cm 空白，小问间不额外留。选择题、判断题不留大块空白；普通填空保留空格或横线。MD 标注“〔答题区：4.5 厘米〕”，不尝试模拟物理高度。

## 执行流程

1. **检查输入与工具。** 识别文件格式、文本层、扫描页、语言、章节及题目分布。优先直接解析 DOCX/PDF 的文字和内嵌图片，再对照页面；扫描页或失真的文本层使用页面图像识别。DOC 和其他格式用实际可用的转换器，不能通过改扩展名转换。工具、OCR、字体、编译器依用户环境选择，不绑定付费 API。缺少依赖或现有方法失败时说明具体障碍并询问，不默默丢弃页面。安装或外部服务是否需要确认依当前用户授权处理。
2. **建立完整页序和题目清单。** 阅读 [识别与清理规则](references/extraction.md)。内部记录源页定位、跨页题、公共材料、章节边界及每页处理状态；这些源页定位不进入正式题目正文。长文档分批处理，保持一个覆盖全部页面的清单，不能以抽样替代全量提取。
3. **整理单一内容源。** 用结构化记录保存章节、题目类型、新旧题号、小问、正文、公式、图片、答题区及疑点。MD 和 LaTeX 从同一批已整理记录生成，PDF 编译自交付的 LaTeX。不要独立重复转写三版。
4. **清理并复核。** 按下方两类疑点规则处理。先完成全部能完成的提取，再集中询问未解决的问题，不因单处疑点逐题打断。无疑点时直接完成，不增加确认步骤。
5. **输出和检查。** 阅读 [交付与验收规则](references/output.md)，以 [A4 LaTeX 模板](assets/chapter-template.tex) 为起点，按实际语言调整字体及排版。生成每章三个版本和完整 ZIP；编译、渲染并检查全部 PDF 页面。确认页码、编号、图片、字形、公式和空白答题区正确后交付。

## 两类疑点必须区分

**身份不明：可能是答案或作答痕迹。** 用不同证据或识别方法再核对，例如放大原图、对照文本层、邻页样式或另一种可用 OCR。默认初次判断后最多再做两次有意义的复核，不能无期限重试。仍无法判断则删除该局部，不直接删除整题；记录删除位置及原因。若影响题目完整性，列入独立核对清单，结束提取后询问用户。不要在清单中重新抄出已删除的疑似答案。

**身份明确：属于原题但识别不清。** 不猜测文字、数字、单位、公式或图形细节；先以“〔待核对〕”标记并完成其余内容。之后集中提供局部定位和具体问题，等待用户回答后生成最终三版。需要预览时仅交付明确标记为草稿的文件；未解决内容不能被当作完整最终版。如用户明确要求保留占位交付，可按其指示生成并说明未解决项。

## 完成报告

简述文件、章节及题目数量，提供输出目录和 ZIP 链接；有疑点时给出独立核对清单。诚实报告无法识别、无法清理或无法编译的部分。仅有 `.tex` 不代表已经生成 PDF；只有全部最终文件实际存在、检查通过才称为完成。
