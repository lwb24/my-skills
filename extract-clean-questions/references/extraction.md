# 识别与清理规则

## 页面、章节和阅读顺序

先盘点全部输入页面与章节，再按自然阅读顺序处理多栏、表格内题目和跨页题。PDF 文本提取顺序不一定是阅读顺序，必须对照渲染页面。扫描页先纠偏、旋转并在需要时放大；保留未修改的原件。

内部每题至少记录：所属文件与章节、源页或范围、原题号、新题号、题型、题干和小问、公共材料引用、图片引用、是否留答题区、处理状态。可用 JSON 等临时结构，不必为了遵守格式增加用户交付物。

利用目录、正文标题及连续内容共同判断章节；目录只作定位线索，不输出。避免把“选择题／填空题”等题型分组当成独立章。章节边界含糊时先完成可确认部分，最后集中询问。无题目的章不生成空文件，记录在处理统计中。

公共阅读材料或配图应置于关联题目前，不能为了“只保留题目”而删除。跨页题合并为完整一道；多个小问保持从属关系。不把一个大题下的小问重新编号为独立大题。原文重复题保留。

## 原题、答案与手写内容

通过语义、版面、笔迹层次、题号及邻近题目的模式识别原题，不以颜色、字体或手写与否单独决定。

- 手写的题干、条件、选项、题号及原始图形应转写或重绘后保留。
- 后加的演算、填入空格的文字、正确选项标记、评分及解析删除，恢复作答空白。
- 保留所有正常选项，包括恰好正确的选项；去掉加在选项上的正确性标记，不通过解题寻找答案。
- “证明以下结论”、翻译题给出的句子、化学反应式题的已知物质，以及例题的题干条件都属于原题。
- “提示”“解”“答案”“解析”等标题是线索，不是机械删除规则；题干要求分析某段解答时，该解答可能正是考查材料。
- 答案紧邻或嵌入题干时仅删除答案部分，保留句法、单位、横线及足够作答位置。

若某局部无法确定是否原题，遵循 SKILL.md 的复核后局部删除规则；若确定是原题但看不清，保留待核对占位。不能为了让成品看似完整，凭常识补题、推算缺失数值或捏造图形关系。

## 配图与水印

优先提取完整、清晰的内嵌资源；扫描图按题意裁切，保留坐标轴、单位、图例、刻度、标签和必要边界。图表、地图、乐谱、电路、分子结构和几何图都可能携带题目条件。

先定位并区分水印和题目图像。仅在能够确认不损坏题意的区域进行清理；简单几何图、坐标图或表格允许忠实重绘，逐项核对原图。不能把需要学生补画的结构自行画好。

复杂照片或被遮挡图形不能凭空补全。痕迹与有效信息重叠时保留内部原图供复核，成品不得偷偷沿用含答案的脏图；标记缺失配图或不明细节，提取完成后集中询问。输出资产只包含清理后的图，不打包含答案或水印的原始截图。

使用图像编辑工具时遵循实际可用工具的编辑规定。原生向量图优先以向量方式重绘，文字与数学内容不依赖生成式图片来保证正确。

## 集中核对

在独立清单中使用“文件／章节／新题号／问题／需要确认的内容”定位，不在正式题目中添加原书页码。内部可保留源页映射方便回查。对于明确原题的识别疑点，可以给出局部图供用户确认；不要将带答案原图混入正式交付包。

先处理全部可确认内容，再一次性询问未解决疑点。用户回应后同步更新共同内容源及三个版本，再复查受影响题目与分页。
