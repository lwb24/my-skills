# 交付与验收

## 目录与内容一致性

每个输入文件建立独立目录，用序号避免同名冲突；每章建立一个目录，含 `questions.md`、`questions.tex`、`questions.pdf` 与所需 `assets/` 图片。文件夹名用安全的序号和简短章名。没有章节时仍按同样结构输出一个单元。不要生成全书合并版。

PDF 由同目录交付的 `.tex` 编译，MD 与 `.tex` 从相同整理内容生成。所有图片使用相对路径，ZIP 包含全部依赖资源及需要时的独立核对清单；不包含原文件、源页映射、OCR 中间文件或编译日志。不把系统字体擅自复制进交付包。

Markdown 使用 UTF-8、章／节标题、显式题号、常见 `$…$` 与 `$$…$$` 数学公式及相对图片路径。大题后写“〔答题区：4.5 厘米〕”。Markdown 的分页依阅读器而定，不伪造固定页码；固定的新页码以 LaTeX/PDF 为准。

## LaTeX 与语言

`assets/chapter-template.tex` 是中文及拉丁文字的 XeLaTeX 起点，替换示例题及标题，不把示例作为真实输出。根据输入语言选择字体和语言包：例如右向左文字需要相应的方向支持，复杂文字需要可用的整形字体。必要时改用 LuaLaTeX 和合适的语言配置。不能声称模板的默认字体覆盖所有语言。

对用户原文中的 LaTeX 特殊字符作恰当转义，数学内容放入数学环境。按需要使用化学式、表格、乐谱或图形工具；若没有可靠的原生表达，使用清晰且已核对的局部图像。不要把完整题目或整页作为图片来冒充可编辑转写。

## A4 排版

- A4 纵向单栏，默认四边 20 mm 边距，正文约 11 pt，可按语言微调；页脚仅放当前章新页码，章内连续，每章重新从 1 开始。
- 保留章节名称，有用的节标题和题型分组可保留，不保留原页眉页脚、原页码或多余装饰。
- 每道需书写过程的大题后留 45 mm 高的空白块，小问之间不额外留。选择题、判断题不加该块；普通填空只保留填写位置。混合题按整体需要书写过程与否判断。
- 模板的 `\AnswerSpace` 提供不可分割的 45 mm 空白块；应结合实际题高分页，避免把答题区孤零零推到下一页或留下只含空白的新页。必要时将整道短题提前到下一页，长题允许自然跨页并让末段和答题区相邻。
- 图片跟随相关题目且不随浮动体漂移到其他题目。超宽表格和图片合理缩放，保证文字可读；题号不孤立在页底。

## 验收

1. 对照源文档的页面清单核对题目覆盖、次序、章节归属、公共材料及跨页拼接；已排除的页面有明确分类。
2. 每章题号从 1 连续递增，小问关系正确；题内交叉引用随编号更新。每章 PDF 页码从 1 连续递增。
3. 对照源图核查公式、上下标、正负号、单位、图例、刻度和特殊字形；不以 OCR 置信度替代视觉核对。
4. 编译 LaTeX，检查错误、缺字、缺图、未解析引用和溢出。按需要重复编译以稳定引用；只有退出成功并存在有效 PDF 才算编译通过。
5. 渲染并查看每一页，确认无截断、重叠、乱码、意外空白页或题图分离，答题区与对应大题相邻且高 45 mm，选择／判断题无该留白。
6. 比对 MD、LaTeX 和 PDF 的题号、文本、公式与配图，排除残留答案、水印和作答标记。核查包内所有相对图片链接，确保脱离原工作目录仍可使用。

若环境无法编译、渲染或识别所需文字，先尝试实际可用的等效方法；仍受阻时具体说明缺失依赖并询问用户。不可用空文件或改扩展名替代 PDF，不把未经验证的输出称为已验收。
